# CyberStrike — Game-Theoretic Cyber Attack & Defense

A self-contained browser game for a Game Theory project. No Node.js, Python, database, API key, or server is required.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome or Microsoft Edge.
3. Choose Campaign, AI Battle, or Equilibrium Challenge.

## Campaign / AI Battle
- You are the Defender.
- AI controls the Attacker.
- Read target probabilities.
- Choose one defense and click DEPLOY DEFENSE.
- The AI chooses an attack target and attack type.
- The game calculates attacker/defender payoffs, damage, score, and network health.
- The AI updates target weights after every round, demonstrating repeated-game adaptation.

## Defense strategies
- Web Shield
- Database Lock
- Deploy Honeypot
- Secure Email
- Monitor Network

## Game Theory
The game demonstrates non-cooperative strategic decision-making, payoff matrices, best-response reasoning, resource allocation, repeated-game adaptation, and a separate pure-strategy equilibrium challenge.

## Safety
This is an educational simulation. It does not perform real cyber attacks, scan networks, send phishing messages, or access credentials.
